BottleMap은 서울대학교 SWPP 2026 수업 프로젝트 팀 Zero to One (Team 19)이 운영합니다. Zero to One(이하 “운영팀”)은 BottleMap 서비스 제공을 위해 다음과 같이 개인정보를 처리합니다.

1. 개인정보의 처리 목적과 항목

구분 처리 목적 처리 항목 법적 근거

사업자 진위 확인 국세청 사업자등록정보 진위확인 서비스로 사업자등록정보 확인 사업자등록번호, 대표자명, 개업일, 진위 확인 결과·시각 서비스 이용계약의 체결·이행 (제4호)
매장 및 메뉴 관리 매장 사진 등록, 메뉴 추출·검수·게시 업로드한 매장·메뉴 사진 또는 PDF, 메뉴 추출 결과, 검수 내용, 게시된 매장·메뉴 정보 서비스 이용계약의 체결·이행 (제4호)
검색 및 근처 매장 안내 검색 결과 제공, 거리 계산, 검색 품질 개선 검색어, 검색 횟수 집계. 현재 위치와 지도 표시 영역은 Android 앱 안에서 거리·반경·표시 매장을 계산하는 데 사용합니다. 서비스 이용계약의 체결·이행 (제4호). 검색 횟수 집계는 운영팀의 정당한 이익 (제6호)
앱 사용 기록 앱 오류와 사용 흐름 분석을 통한 품질 개선 앱 사용·화면 이동 이벤트, 오류 코드와 API 경로 형식, 크래시·앱 응답 없음 기록, 앱 버전, 기기 모델·운영체제, 앱 설치 식별자, IP 주소를 이용해 추정한 대략적인 지역 정보주체의 동의 (제1호)
문제 신고 이용자 문의 접수 및 문제 해결 이용자가 작성한 신고 내용, 앱 버전, 기기 정보. 신고 양식에서 이름·이메일·전화번호를 입력받지 않습니다. 이용자 요청에 따른 조치의 이행 (제4호)
서비스 운영 및 보안 장애 대응 및 부정 이용 방지 IP 주소, 접속 시각, 요청 경로·상태 등 접속 기록 운영팀의 정당한 이익 (제6호)

표의 법적 근거는 「개인정보 보호법」 제15조 제1항 각 호를 가리킵니다. 운영팀은 앱 사용 기록의 수집과 신청자 연락처의 고객 공개만 정보주체의 동의를 받아 처리하며, 그 밖의 항목은 동의 없이 표에 적은 근거에 따라 처리합니다.

매장 검색과 게시된 메뉴 열람은 로그인 없이 이용할 수 있습니다. Android 앱은 현재 위치와 지도 표시 영역을 기기 안에서 처리하며 BottleMap 서버로 보내거나 저장하지 않습니다. 다만 지도를 그리기 위해 표시 영역 정보가 지도 제공자(Kakao)에 전달됩니다(제3조). 검색어는 서버 접속 기록에 포함될 수 있습니다.

신청자 연락처는 업주 심사를 위한 연락에 사용합니다. 매장 전화번호가 없는 경우에는 신청자가 별도로 공개에 동의한 때에만 이 번호를 고객에게 표시합니다. 운영팀이 정의해 전송하는 앱 사용 이벤트에는 검색어 원문, 정확한 위치 좌표, 이름·이메일, 사업자등록번호, 사진을 포함하지 않습니다. 다만 분석 서비스는 IP 주소로 대략적인 지역을 추정할 수 있습니다. 문제 신고용 Google Form은 응답자의 Google 계정 이메일을 자동 수집하지 않으며 연락처 입력란도 두지 않습니다.

2. 개인정보의 보유 및 이용 기간

구분 보유 기간
회원 정보 회원의 탈퇴·삭제 요청 또는 서비스 종료 중 먼저 도래하는 때까지 보유합니다.
업주 신청 정보와 심사 이력 회원의 탈퇴·삭제 요청 또는 서비스 종료 중 먼저 도래하는 때까지 보유합니다. 반려·취소된 신청 내역도 별도 장기 보관하지 않습니다.
매장·메뉴 사진, 추출·검수 기록 매장과 메뉴를 관리하는 데 필요한 동안 보유합니다. 업주의 삭제 요청이 있으면 개인정보가 포함된 부분을 확인해 삭제하고, 서비스 종료 시 남은 기록을 파기합니다.
검색 결과가 없었던 검색어의 날짜별 집계 최근 30일분을 관리하며, 새 집계 정보가 생성될 때 지난 집계를 삭제합니다.
상품별 검색 횟수 집계 최근 90일분을 관리하며, 새 집계 정보가 생성될 때 지난 집계를 삭제합니다.
신청 전 사업자 진위 확인 결과 일치한 결과를 서버 메모리에서 최대 30분간 재사용합니다. 신청 시 저장되는 확인 결과의 보유 기간은 업주 신청 정보의 보유 기간을 따릅니다.
Google Analytics for Firebase의 사용자·이벤트 데이터 2개월로 보유 기간을 설정합니다. 집계 보고서에는 이 설정과 다른 보유 기준이 적용될 수 있습니다.
Firebase Crashlytics의 크래시 기록 Google의 서비스 보유 정책에 따라 크래시 기록과 관련 식별자는 90일 보관 후 삭제 절차가 시작됩니다.
문제 신고 내용 처리 완료 후 90일 동안 보유한 뒤 삭제합니다. 공개 GitHub 이슈에는 개인 식별 정보를 제거한 문제 요약만 남깁니다.
서버 접속 기록 30일 동안 보유한 뒤 삭제합니다.
데이터베이스 자동 백업 복구를 위해 보관 기간을 1일로 설정합니다. 수동 스냅샷은 보유하지 않습니다.

4. 개인정보의 파기

운영팀은 개인정보의 보유 기간이 끝나거나 처리 목적이 달성되어 더 이상 필요하지 않을 때 해당 정보를 파기합니다. 개인정보 삭제 요청이 들어오면 본인 확인 후 BottleMap 데이터베이스의 계정·신청 정보와 Supabase Auth의 로그인 계정을 수동으로 삭제하고, 매장·메뉴 자료에 남은 개인정보도 확인해 삭제합니다. 전자 기록은 데이터베이스와 파일 저장소에서 삭제합니다. 데이터베이스 자동 백업은 1일 보관 기간이 지나면 교체되며, 수동 스냅샷은 보유하지 않습니다.

대기 중인 업주 신청을 취소하거나 운영팀이 신청을 반려하면 신청에 첨부된 메뉴·매장 사진을 삭제합니다. 신청 내역과 심사 기록은 보유 기간에 따라 처리합니다. 메뉴 등록 작업을 취소해도 업로드한 사진과 AI 추출 기록은 즉시 삭제되지 않습니다.

5. 정보주체의 권리와 행사 방법

정보주체는 자신의 개인정보에 대한 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다. 표시 이름은 서비스에서 직접 수정할 수 있습니다. 그 밖의 요청은 제8조의 연락처로 제출할 수 있습니다. 개인정보 보호책임자가 본인 여부를 확인한 뒤 BottleMap 계정·업주 신청 정보와 Supabase Auth 로그인 계정의 삭제 요청을 수동으로 처리하며, 메뉴·사진에 개인정보가 남아 있는지도 확인해 필요한 조치를 합니다. 대리인이 요청하는 경우에는 대리 권한을 확인합니다. 처리 결과에 이의가 있으면 같은 연락처로 다시 문의할 수 있습니다.

BottleMap은 만 19세 이상인 사람을 대상으로 합니다. Android 앱에서는 서비스 이용 전에 만 19세 이상인지 확인하고, 확인하지 않으면 이용을 진행하지 않습니다. 이 확인은 이용자의 자기확인에 기반하며 신분증 등으로 실제 연령을 인증하지 않습니다. 만 19세 미만인 사람의 개인정보가 처리된 사실을 확인한 경우에는 제8조의 연락처로 알려 주시면 본인 여부를 확인한 뒤 삭제 등 필요한 조치를 합니다.

6. 개인정보의 안전성 확보 조치

운영팀은 보호가 필요한 API에 로그인 토큰 검증과 권한 확인을 적용합니다. 사업자등록번호는 암호화해 저장하고, 사진 파일은 비공개 저장소에 보관합니다. 서비스 통신에 HTTPS를 적용하고 서버 접속 기록에서 위치 좌표를 제거합니다.

7. 자동 수집 및 저장 정보

서비스 이용 과정에서 접속 기록이 생성됩니다. 업주용 웹은 로그인 상태 유지를 위해 브라우저에 인증 세션을 저장합니다. 작성 중인 업주 신청은 다시 이어서 입력할 수 있도록 사업자등록번호·대표자명·개업일·연락처 등 입력 내용을 브라우저 저장소에 임시 보관하며, 신청 완료 또는 로그아웃 시 삭제합니다. 신청 사진은 이 저장소에 보관하지 않습니다. 업주용 웹은 메뉴 검수 중 서버에 아직 저장되지 않은 수정 내용을 브라우저 저장소에 임시 보관하며, 서버에 저장되거나 검수를 마치면 삭제합니다. Android 앱은 인증 세션과 최근 검색어(최대 8개)를 기기에 저장합니다. 최근 검색어는 서버로 보내지 않으며, 검색 화면에서 지울 수 있습니다.

Android 앱은 이용자가 첫 실행 화면이나 앱의 내 정보 → 사용 기록 보내기에서 수집을 켠 경우에만 Firebase Analytics와 Crashlytics를 통해 앱 사용 이벤트와 오류 정보를 수집합니다. 이용자는 같은 메뉴에서 두 서비스의 수집을 언제든 함께 끌 수 있습니다. 앱은 광고 ID를 수집하거나 Firebase에 별도의 사용자 ID를 설정하지 않습니다. 웹의 임시 신청 정보는 로그아웃하거나 신청을 완료하여 삭제할 수 있으며, 브라우저 저장소를 지워서도 삭제할 수 있습니다. 웹 로그인 세션은 로그아웃하거나 브라우저 저장소를 지워 삭제할 수 있습니다.
