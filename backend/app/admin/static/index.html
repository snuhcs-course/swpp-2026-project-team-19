요청 수 초기화

  • 사용자마다 국세청 진위확인은 하루 30회, 사업자등록증 OCR은 하루 5회까지 할 수 있고, 한국 시간 자정에 초기화돼요.
  • 횟수는 서버 메모리에 있어서 서버를 재시작해도 초기화돼요.
  • 앱에서 아직 BottleMap 사용자로 등록되지 않은 사람은 개별 초기화가 안 되고, 전체 사용자 초기화로만 풀려요.
  • 사용자 ID는 업주 신청 상세의 "사용자 ID"에서 복사할 수 있어요.
