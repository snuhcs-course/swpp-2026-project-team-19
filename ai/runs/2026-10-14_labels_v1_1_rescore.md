# L1 결과: 라벨 v1.1(메뉴판 인쇄 표기) 재채점

2026-10-14 · 박진우 (실행·분석: Claude Code, 수정안 승인·판독: 박진우)

**무엇을 했나.** 라벨 `raw_name`을 메뉴판에 인쇄된 그대로 고친 v1.1을 만들었다. 기존 출력은 그대로 두고 라벨만 v1.1로 바꿔 다시 채점했다. API 호출은 0회(Gemini 0, CLOVA 0)다. 기존 리포트(P11 요약, P12 `report.md`, P22 `eval_plan.md`)는 고치지 않았다.

## 결론

1. **판정은 하나도 바뀌지 않는다.** P12 판정 Δ(CLOVA+LLM − E1, test 항목 정답률)는 v1 +0.040, v1.1 +0.041로 둘 다 기준 +0.03 이상이다. P22에서는 모든 매처·조건의 false merge가 v1.1에서도 0이므로 S1+S2b+S3 채택이 그대로다.
2. **항목 정답률은 거의 그대로다.** 바뀐 이름은 대부분 편집거리 1이라, v1에서도 관대 일치로 이미 짝지어졌다. 변화는 E1 test −0.001, 나머지 0이다.
3. **엄격 F1은 CLOVA+LLM test에서 +0.071이다** (0.841 → 0.912). CLOVA가 인쇄대로 읽은 이름 124건이 관대 일치에서 엄격 일치로 올라갔다. E1은 표준 표기로 쓴 경우와 인쇄대로 쓴 경우가 섞여 있어 거의 그대로다(+0.001).
4. **매칭은 약간 내려간다.** 알려진 상품 Top-1이 test에서 −0.003~−0.008이다. 매처의 별칭이 표준 표기(캐리비안, 스트렝스)여서, 인쇄 표기를 입력으로 넣으면 2줄을 잃고 1줄(셰리캐스크)을 얻는다.

### 바뀐 숫자의 원인 (3회 합계, 라벨 항목 기준)

수정한 항목 외에 짝이 바뀐 항목(연쇄 효과)은 세 조건 모두 0건이다.

**E1 val**
- F1 엄격 −0.006: 퀸타루반→퀀타루반 때문이다. E1은 "퀸타루반"(표준 표기)으로 읽었다. 4건이 엄격에서 관대로 내려갔고, 관대 일치로 정답 처리는 그대로다.

**E1 test** (항목 정답률 −0.001 = 3회 합계 정답 −1건, 오탐 +1건)
- 맥캘란→맥켈란: 엄격→관대 8, **관대→누락 8**. E1은 "맥캘란(Maccallan) … 세리 캐스크"나 "맥캘란(Macallan) …"으로 썼다. v1에서는 편집 1(세리/셰리, Maccallan/Macallan)이라 관대 일치였는데, 켈/캘 차이가 하나 더해져 편집 2가 되면서 짝을 잃었다. 정답률 하락의 원인은 이것 하나다.
- 스트렝스→스트랭스: 관대→엄격 40, 엄격→관대 36, 관대→누락 3, 누락→관대 4. E1이 회차·사진마다 "스트랭스"(인쇄)와 "스트렝스"(표준)를 섞어 써서 거의 상쇄됐다. 순 효과는 짝 +1.
- 아몬티야도→아몬티야또: 누락→관대 3. 짝 +3.
- 커티샥→커디샥: 관대→엄격 2, 누락→관대 1. 엡버스→엠버스도 같다(관대→엄격 2, 누락→관대 1). 언익스팩티드→언익스펙티드도 관대→엄격 2, 누락→관대 1. 각각 짝 +1.
- 에리너→에리네 3, 시그니쳐→시그니처 3, 미야기쿄→미아기쿄 2: 관대→엄격. 엄격 F1만 오른다.
- 세리캐스크→셰리캐스크 3, 퓨전→퓨젼 3, 캐리비안→캐리비언 3: 엄격→관대. E1이 표준 표기로 읽은 경우로, 엄격 F1만 내린다.

**CLOVA + LLM test** (F1 엄격 +0.071)
- 관대→엄격 124건이다(본 채점의 짝 기준이고, F1 엄격이 쓰는 엄격 전용 짝으로는 1,438 → 1,560, +122건): 스트랭스 77, 맥켈란 18, 커디샥·엠버스·셰리캐스크·아몬티야또·언익스펙티드·퓨젼·캐리비언 각 3, 에리네·시그니처·미아기쿄 각 2. 2단계 LLM이 OCR 글자를 그대로 옮겼기 때문에, 라벨이 인쇄와 같아지자 전부 엄격 일치가 됐다.
- 항목 정답률·관대 F1이 그대로인 것은 v1에서도 모두 관대 일치로 정답 처리됐기 때문이다.

**P12 판정 다시 계산:** CLOVA+LLM 0.883 − E1 0.842 = **+0.041** (v1 +0.040). 기준 +0.03 이상이고 판정은 같다.

**해석.** 인쇄 표기는 표준 표기와 1~2글자 다르다. 지금 매처는 정확 별칭(S1·S2)과 편집거리(S3)에 기대고, 별칭이 표준 표기라서 인쇄 표기 입력에 조금 약하다. 실제 운영 입력은 인쇄 표기(OCR·Vision 출력)이므로, v1.1 숫자가 운영에 더 가깝다.
