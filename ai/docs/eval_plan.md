# BottleMap AI 평가 계획 (P13)

2026-10-04 · 박진우

대표 지표는 **항목 정답률**이다. 업주가 고쳐야 하는 줄 수를 직접 나타낸다(TA 피드백: 200줄에 정확도 0.9면 20줄을 손으로 고쳐야 한다). 나머지 지표는 오류 원인을 나누는 데 쓴다.

## 지표 정의 (Iteration 1은 추출 지표만)

| 지표 | 계산 | 분모에서 빼는 것 |
| --- | --- | --- |
| **항목 정답률 (대표)** | 이름이 짝지어지고 가격·unit까지 맞은 항목 수 ÷ (정답 항목 수 + 오탐 수) | 정답 가격이 null이거나 note가 있는 항목은 가격 대신 이름·unit만 본다 |
| 항목 F1 | 짝지어진 항목 수로 Precision·Recall → 조화평균 | 없음 |
| 가격 정확도 | 짝지어진 항목 중 price_krw가 정답과 정확히 같은 비율 | 정답 가격이 null이거나 note가 있는 항목 |

분모에 오탐을 넣는 이유: 메뉴에 없는 줄을 지우는 것도 업주에게는 수정 작업이다.

매칭 지표(Top-1, false-merge)는 카탈로그·별칭 데이터 확정 후 별도 정답으로 잰다. 이번 실험 범위 아님.

## 항목 대응 규칙

같은 사진 안에서, 정규화한 이름과 unit이 같은 항목끼리 짝짓는다.

1. **이름 정규화:** 영문 소문자화, 공백·문장부호 제거. 한/영 병기(`A / B`)는 앞뒤를 각각 후보 이름으로 보고, 하나라도 일치하면 같은 이름. 슬래시는 앞뒤 공백 유무와 관계없이 모두 나누고(`A/B`도 병기로 본다), 나누지 않은 전체 이름도 후보에 포함한다 (2026-10-04 실행 전 추가: 출력의 띄어쓰기 차이로 감점되지 않게, 이름 속 슬래시는 전체 이름으로 짝)
2. **엄격 일치:** 정규화 후 완전히 같아야 짝
3. **관대 일치:** 아래 두 조건을 모두 만족하면 짝
   - 이름 안의 **숫자 부분(숙성연수·도수·배치 번호 등)이 순서까지 완전히 같다.** "글렌피딕12y"와 "글렌피딕15y"는 한 글자 차이지만 다른 제품이라 짝이 아니다
   - 숫자를 뺀 나머지 문자열의 **Levenshtein 편집거리가 1 이하** ("글렌"↔"글랜" 한 글자 오독 허용). 비율 유사도는 이름 길이에 따라 기준이 흔들려서 쓰지 않는다
4. **짝짓는 순서:** 사진별로 엄격 일치를 먼저 모두 짝짓고, 남은 항목끼리 관대 일치. 후보가 여럿이면 편집거리가 작은 것부터. 정답 항목 하나는 출력 항목 하나와만 짝(1:1)
5. 남는 출력 = 오탐, 남는 정답 = 누락

항목 F1은 엄격·관대 둘 다 보고. 목표 비교는 관대 기준.

## 잔·병 혼동 진단

짝짓기 키에 unit이 들어 있어서, unit을 틀리면 오탐 1개 + 누락 1개로 나타난다(대표 지표는 이대로 둔다). 원인을 보기 위해 대응이 끝난 뒤 **남은 오탐과 누락끼리 unit을 무시하고 이름만으로 한 번 더 짝짓는다.** 여기서 짝이 되면 「잔·병 혼동」으로 분류해 건수를 보고한다. 별도의 unit 정확도 지표는 두지 않는다.

## Iteration 1 판정 규칙 (실행 전 확정, 결과 보고 바꾸지 않음)

조건은 `experiment_p14.md` 참고: A = Flash-Lite + thinking minimal, A2 = Flash-Lite + thinking medium, B = Flash + thinking medium. 각 조건의 항목 정답률은 사진당 5회 반복의 평균으로 판정한다 (보고는 평균과 최소~최대). 회차 r의 정답률 = 9장 합산 (맞은 항목 수) ÷ (정답 항목 수 + 오탐 수)이고, 조건의 정답률은 회차 1~5 값의 평균이다. 사진별 정답률을 평균하지 않는다 (항목 0개 사진과 77항목 사진이 같은 무게가 되므로). 위에서부터 처음 해당하는 행을 적용한다.

| 결과 | 결정 |
| --- | --- |
| A ≥ 0.85 | Flash-Lite 기본값으로 계속, 프롬프트 개선 |
| A < 0.85, A2 ≥ 0.85 | Flash-Lite + thinking medium 채택 (thought 토큰 비용 기록) |
| A·A2 < 0.85, B ≥ 0.85 | 모델 상향을 비용과 함께 결정 |
| A·A2·B 모두 < 0.85 | 리스크 R1 비상 대응: OCR + LLM 파싱 검토 |
