# #189 Galaxy S23 검증 안내

대상 브랜치: `feature/i5-p13-issue189-user-errors`  
연관 작업: I5-P13의 오류 안내 회귀 범위. P13 전체 완료를 의미하지 않음.

## 설치

저장소 루트에서 아래 순서대로 실행하세요. 앱 삭제나 데이터 초기화는 하지 않습니다.

```powershell
git fetch origin
git switch feature/i5-p13-issue189-user-errors
git pull --ff-only
.\gradlew.bat :app:installDebug "-PBOTTLEMAP_API_BASE_URL=https://bottlemap.o-r.kr/"
```

`git switch`가 원격 브랜치를 자동 추적하지 못하면 두 번째 명령만 다음으로 바꿉니다.

```powershell
git switch --track origin/feature/i5-p13-issue189-user-errors
```

설치 전 `adb devices -l`에서 Galaxy S23이 `device`인지 확인합니다. 검증한 커밋은 `git rev-parse --short HEAD`로 기록합니다. 저장소의 `android/qa/issue189-device-qa.html`을 브라우저에서 열면 항목별 통과·실패·미확인을 선택하고 **결과 복사**로 한 번에 복사할 수 있습니다.

## 확인할 변경

화면 배치나 버튼 위치 변경이 아니라 오류 문구 변경입니다. 내부 HTTP/예외/필드명 또는 서버 원문 대신 한국어로 이유와 다음 행동을 안내해야 합니다. 승인된 사진 업로드 상단 토스트, 신청 한도 안내, 게시 결과 불명 상태 확인 경로는 유지합니다.

1. Customer에서 비행기 모드로 검색·바 상세 조회: 원시 영문/HTTP/예외 없이 연결 확인과 재시도 안내. 이미 캐시된 화면이면 새 조회가 필요한 경로로 확인합니다.
2. 로그인된 내 정보에서 비행기 모드로 매장 상태 조회: 사용자용 오류·재시도 표시. `Cannot reach`, `Request failed`, 내부 예외가 없어야 합니다.
3. 내 매장 정보 수정 화면에서 비행기 모드로 저장: 한국어 실패 안내. 저장 성공으로 오인시키지 않고 입력을 유지합니다. 온라인으로 전환하기 전에 의도하지 않은 수정은 취소하세요.
4. 수동 메뉴 수정에서 오프라인 저장 실패: 내부 필드명·영문 상세 오류 없이 안내. 정상 저장된 기존 메뉴가 유지됩니다. 의도하지 않은 메뉴 변경을 온라인으로 제출하지 마세요.
5. 저장된 사진 검수 초안에 재진입 후 오프라인 입력/저장·재시도: 기존 오류/복구 화면을 유지하고 한국어 안내. 재연결·앱 재시작 뒤 이전에 정상 저장한 검수 값이 유지되어야 합니다. 검증을 위해 운영 메뉴를 게시할 필요는 없습니다.
6. 조회 중 뒤로 가기/탭 이동: 코루틴 취소 문구나 스택 추적이 나타나지 않습니다.
7. 재연결 후 기존 다시 시도 버튼: 정상 조회·화면 복구. 중복 제출하지 않습니다.
8. 온라인 Customer 검색·바 상세·지도·Google/Guest 기본 경로: 기존 동작 유지.
9. 401/403/409/한도·입력 오류: 준비된 테스트 계정/테스트 환경이 있는 경우에만 확인. 강제로 권한·운영 데이터나 한도를 변경하지 않습니다. 로그인·권한·최신 정보·입력 수정처럼 상태에 맞는 안내가 필요합니다. 재현하지 못했으면 미확인으로 남깁니다.

## 현재 검증 상태

로컬 패치 적용/변경 범위 검사는 완료했습니다. 로컬 Gradle은 배포 파일 다운로드가 네트워크 제한으로 실패하여 빌드·JUnit·Lint 결과가 없습니다. GitHub CI 결과는 PR의 Checks에서 별도 확인합니다. 실기기 검증은 사용자 보고 전까지 미확인입니다. 새로운 검색/연령 체크/연락처 UI task는 이 PR의 범위가 아닙니다.
